# 桌面连接器方案（受控回传，v5 P2）

> 状态：方案稿（2026-09-13，待叶森立项确认）。对应 v5 改进报告 P2「受控回传」：
> 验收 = 从工作事项直接打开文字处理文件，编辑后受控回传为新版本，记录编辑人并检测冲突。

## 一、它是什么、解决什么问题

律师在系统里查看材料后，仍要"下载 → 本地用 Word/WPS 编辑 → 再上传"，中间产生三个失控点：

1. **副本失控**：下载件散落桌面，改了哪版说不清；
2. **回传靠自觉**：忘记上传、上传错版本、覆盖他人刚传的版本；
3. **冲突不可见**：A 打开编辑期间 B 也回传了新版，A 再传即静默覆盖。

桌面连接器是一个安装在律师电脑上的**极小本地助手**（常驻托盘），只做三件事：
**受控取件 → 本地编辑 → 受控回传**。不是同步盘、不是客户端壳——LawLink 仍是唯一事实源。

## 二、架构与交互（MVP）

```
浏览器/系统 ──点击「在桌面打开」──▶ lawlink://open?doc={id}&token={一次性令牌}
                                        │
                                 桌面连接器（本地，托盘常驻）
                                        │ ① GET /api/desktop/checkout {docId, token} → 下载原件
                                        │    放入 ~/LawLink/{matter编号}/{文件名}（受控目录）
                                        │ ② 文件被打开编辑（连接器只监听该目录，不碰其他文件）
                                        │ ③ 保存后点托盘「回传」或关闭文件自动提示
                                        │    POST uploadNewVersion（走既有版本链！familyId/vN/isLatest）
                                        └ ④ 服务端比对期间有无他人新版本 → 有则提示合并/另存
```

关键决策：

- **自定义协议唤起**（`lawlink://`）：浏览器一键唤起本地助手，免除"下载找文件"步骤；
- **checkout/回传令牌**：短期一次性 token（复用附件下载令牌机制），令牌绑定 docId+用户+15 分钟；
- **回传复用 `uploadNewVersion`**：版本链、isLatest 翻转、审计 `DOCUMENT_NEW_VERSION` 全部继承，连接器零新权限模型；
- **冲突检测**：checkout 时记录 `基线版本号 vN`；回传时服务端发现已是 vN+k（k>0）→ 拒绝直传，返回冲突详情与最新版下载，连接器弹"基于新版另存副本"（不自动合并——法律文本不搞自动合并）；
- **编辑人留痕**：回传即审计（谁、何时、基于哪版、改后哈希），目录内文件只读属性标记"受控副本，勿外发"（提示性，不做 DRM）。

## 三、技术选型（候选，立项时定）

| 项 | 推荐 | 理由 |
|---|---|---|
| 连接器形态 | Tauri 2（Rust + 系统 WebView） | 体积 ~5MB，无 Electron 负担；文件监听用 notify crate |
| 协议注册 | Tauri deep-link 插件 | Windows 注册表 / macOS Info.plist 一步到位 |
| 文件监听 | notify（保存触发）+ 手动回传按钮 | 双保险，避免只靠自动 |
| 服务端新增 | 2 个 API：checkout（发令牌+记基线）、（回传复用既有 action） | 改动面最小 |

## 四、分步实施（立项后）

1. **服务侧先行**（半天）：checkout API + 基线版本记录 + 冲突判定逻辑 + 审计；
2. **连接器 MVP**（2-3 天）：deep-link、受控目录、手动回传、冲突弹窗；
3. **打磨**：托盘状态、多文件、WPS/Word 兼容性矩阵、Windows/macOS 双平台安装包；
4. **验收**：按 v5 口径——回传成版本、记录编辑人、冲突被拦截三条用例 + 越权令牌测试（过期/换人/换文档）。

## 五、明确不做

- 不做网盘式双向同步（法律文件不允许同步覆盖语义）；
- 不做自动合并冲突文本；
- 不做移动端；
- 不内嵌编辑器（Word/WPS 是事实标准，浏览器内编辑另立项）。

## 六、风险

| 风险 | 缓解 |
|---|---|
| 企业 IT 禁装本地程序 | 提供降级路径：现有"下载 + 手动上传新版本"流程不变，连接器是增强不是依赖 |
| 文件锁/WPS 另存习惯 | 回传按钮允许手动选文件兜底，不强制监听 |
| 令牌泄露 | 一次性、15 分钟、绑定用户与文档，复用已有短期令牌审计 |
