# 律师团队：实现与迁移审阅

## 已确认口径

系统超级管理员（ADMIN）设置团队负责人、成员和额外查看人员。负责人自动成为获权成员。团队负责人登录后，在原案件列表“全部可见”中自动看到当前团队成员原始立案或当前主办的全部案件，包含历史案件；状态筛选继续生效。不设置案件所属团队，不逐案授权。普通成员不自动互相开放案件，跨团队协办不传播团队查看权。

当前成员关系决定可见范围。退出成员、撤销查看权限或停用团队后，下一次请求按新关系查询。原有个人经办权限保留；账号停用不抹除其历史案件归属。支持一人加入多个团队。

## 入口与权限

- 设置 → 律师团队：创建、编辑、停用；仅 ADMIN 能维护，负责人和额外查看人员不能自行扩大成员范围。
- 案件列表：全部可见 / 我经办的 / 团队案件，可按获权团队和主办筛选；搜索、分页和状态条件与范围取交集。
- 团队只读详情：案件信息、当事人、程序、期限、沟通记录和进展。原有财务、材料下载和写入权限独立校验。收案列表只返回页面所需字段；只读收案详情不返回收费、文件与完整冲突命中数据。
- 工作台案件统计及全局案件搜索同步包含团队范围；财务统计、材料搜索、客户独立档案保持原权限。
- 日程页面可显示团队日程；ICS 订阅沿用既有个人/全所角色范围。
- 导出始终与既有导出权限取交集；仅团队可读的案件不会新增导出权限。
- 协办人员选择：我的团队优先，全所其他人员可搜索；已选人员在搜索时仍可见，既有停用协办可移出但不能重新新增。

1. 新增 Team 和 TeamMember，成员退出保留关系并标记 inactive。
2. Matter 新增可空 registeredById 原始立案人字段、索引、外键。
