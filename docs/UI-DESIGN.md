## v3.4 当前规范（执行版）

### 一、设计方向

LawLink V1 当前采用 **冷调灰白底 + 原有 teal 主色 + 高密度业务界面**。

目标不是做营销页，也不是普通后台，而是给律师高频使用的案件管理工具：信息密度要高、状态要清楚、页面层级要稳，操作入口要贴近业务流程。

### 1.1 Apple 式质感的边界

LawLink 采用 Apple 设计中的直接反馈、空间一致、克制材质和平台字体，不模仿 macOS 窗口外观：

- **直接**：按钮在按下时立即反馈；高频页面和键盘操作不播放整页入场动画。
- **克制**：毛玻璃只用于顶栏、浮层和抽屉等悬浮结构，表格、表单和案件正文保持实体表面，禁止多层玻璃叠加。
- **精确**：普通 UI 动效控制在 140—240ms，抽屉控制在 220—300ms；默认不弹跳，只有真实拖拽、甩动等动量交互可使用轻微弹簧。
- **连续**：popover、dropdown、tooltip 从触发位置出现，进入和退出保持同一路径；可中断交互从当前画面值继续。
- **可访问**：尊重 `prefers-reduced-motion`、`prefers-reduced-transparency` 和 `prefers-contrast`，降级后仍保留状态反馈和清晰边界。
- **高密度不等于小字**：正文基线保持 13px 左右，关键身份、期限、金额和状态不得依赖 9—10px 文本。

```css
  --bg-glass:    rgba(237,240,244,0.82);

  --bd-subtle:   #DDE2EA;
  --bd-default:  #D0D7E0;
  --bd-strong:   #B8C1CE;
  --bd-accent:   #B8D8D8;

  --t-primary:   #0F1B2D;
  --t-secondary: #3D4A5C;
  --t-muted:     #6B7686;
  --t-faint:     #A8B2C0;

  --primary:     #007B7F;
  --primary-h:   #006669;
  --primary-soft:#ECF4F4;

  --motion-press: 100ms;
  --motion-fast:  160ms;
  --motion-base:  220ms;
  --motion-sheet: 280ms;
  --ease-out:     cubic-bezier(0.23, 1, 0.32, 1);
  --ease-in-out:  cubic-bezier(0.77, 0, 0.175, 1);
  --ease-drawer:  cubic-bezier(0.32, 0.72, 0, 1);

```

`--ease-drawer` 只用于 `Sheet` 一类位移主导的滑入面板（源自 Ionic 的 iOS 抽屉曲线）；

实现时继续使用 shadcn/ui 的 HSL 变量体系，以上 token 映射到 `src/app/globals.css` 中的 `--background`、`--card`、`--primary`、`--border`、`--muted` 等变量。

### 三、布局

- 侧栏：桌面端 `208px`，白底，右侧 1px 浅描边；一级导航分为「工作区」「资料」。
- 顶栏：`48px`，冷灰毛玻璃背景，底部浅描边；保留全局搜索、应用菜单、通知、新建收案、用户菜单。
- 主内容：`max-width: 1440px`，桌面端 `20px` 水平内边距、`16px` 垂直内边距。
- 卡片：白底、浅描边、轻阴影、顶部内高光；页面区块不再堆大留白。

### 五、实现纪律

- v3 是视觉系统迁移，不改业务规则、不绕过权限、不弱化审计。
- mockup 没覆盖的现有功能入口必须保留，尤其是通知、应用菜单、用印审批、开票、材料、归档和系统设置。
- 页面首次出现不应成为统一装饰动作。只有能说明空间关系、反馈状态或避免突变的内容才使用动效；工作台、案件列表、客户、财务、日程和冲突检索等高频路由默认即时呈现。
- 预设动效优先使用 CSS 的 `transform`、`opacity`；手势驱动且需要中断时才使用 Framer Motion 弹簧。禁止 `transition: all`、UI `ease-in`、从 `scale(0)` 出现以及无降级的位移动效。
- **按压反馈**：任何可按压元素（Button、TabsTrigger、侧栏导航、RadioChips）都要有 `active:scale-[0.98]`，配 `--motion-press` + `--ease-out`，并带 `motion-reduce:transform-none`。
- **hover 必须门控**：Tailwind 已开启 `future.hoverOnlyWhenSupported`，所有 `hover:` 变体自动包进 `@media (hover: hover) and (pointer: fine)`。在 `globals.css` 手写 hover 规则或使用 `[&>x:hover]` 这类任意选择器时，必须自己补同样的媒体查询，否则触屏点击后 hover 态会粘住。仅有把样式重置为 `none` 的规则可豁免。
- UI 变更后必须跑 `npm run lint`、`npm run typecheck`、`npm run prisma:validate`、`npm run build`，并打开本地站点检查 `/login` 和核心工作流页面。

### 六、控件一致性

- 同类交互优先走 `src/components/ui/*` 共享组件，不在页面里重复手写 hover / focus / selected 样式。
- **全局单例组件只允许挂一份**：`Toaster` 只从 `@/components/ui/sonner` 引入（样式与图标在该文件定型，不要另起裸 `<Toaster/>`）；`TooltipProvider` 在 `components/providers.tsx` 统一挂载，`delayDuration={300} skipDelayDuration={200}`——首次悬停延迟防误触，相邻 tooltip 瞬开保持跟手。
- `SelectItem`、`DropdownMenuItem`、`CommandItem`、`RadioChips` 以及业务 combobox / 候选列表里的选项统一：鼠标经过 / 键盘高亮为 `bg-muted text-foreground`，已选中为 `bg-accent text-primary` 或对应主色选中态。
- 菜单、下拉、popover 等轻量浮层容器统一：白底、`border-border`、`shadow-medium`、`rounded-md`、紧凑内边距。
- 弹窗 / 抽屉内必须形成内外层级：外层内容区使用 `background` 浅灰，输入框、文本框、下拉框等可编辑方框内部使用 `card` 白色；内外不能同色，也不能同时为白色。
- 表单控件统一：`Input`、`Textarea`、`SelectTrigger` 使用同一高度节奏、细描边、白色底、轻内阴影和轻微立体边框；输入 / 聚焦时边框切换为主色，并出现类似 `08-intake-wizard.html` 的 3px 柔和光晕；下拉箭头贴近方框右侧，避免停在视觉中部。
- 表格式录入区同一列控件外形保持一致；表头文案居中，单元格里的短选项文案居中显示。
- 同一行内的状态、案由等业务徽章高度、字号和圆角必须保持一致，只允许颜色和文案区分语义。
- 收案抽屉的律师费 / 顾问费区域采用高密度录入：收费方式、金额、付款节点和备注优先同排；风险代理仅额外展开一行收费方式说明，不把所有字段纵向铺开。

## 一、设计语言

**"严肃的科技感"** —— 给律师用的工具，不要赛博朋克游戏化，但要现代、克制、有质感。

三个关键词：
1. **暗色为主**：深蓝灰底 + 微弱渐变，长时间看屏幕不疲劳。
2. **玻璃拟态克制使用**：仅顶栏、模态、关键卡片用毛玻璃，列表/表格不用。
3. **微交互而非动画堆砌**：聚焦、悬停、状态切换有动效，但不超过 250ms。

参考产品（用于校准方向，不抄）：
- **Linear**：信息密度 + 暗色 + 干净
- **Vercel Dashboard**：留白 + 渐变线条
- **Arc Browser 设置页**：玻璃质感
- **Anthropic Console**：克制的科技感

**反例**（不要走的方向）：
- ❌ 大量荧光色、霓虹灯效果（赛博朋克）
- ❌ AntD/Element 的浅色卡片堆叠（普通后台）
- ❌ 大圆角 + 厚阴影 + 渐变按钮（Web3 风格）

### 2.2 浅色主题（V1.5 提供，V1 先不做）

预留 `[data-theme="light"]` 切换，但 V1 默认强制暗色（保留 toggle 但置灰）。

### 2.3 主题色自定义（V1 开放）

`--accent-primary`（法理蓝 `#5B8DEF`）为系统默认主色。管理员可在 `/settings/appearance` 选择：

- 法理蓝（默认）`#5B8DEF`
- 法庭金 `#D4A453`（适合传统律所）
- 翡翠绿 `#3FB28F`
- 朱砂红 `#E8694D`（仅用于刑辩所，慎选）

或自定义色值（HEX）。系统会自动派生 `--accent-hover` 与 `--accent-glow`。存到 `SystemSetting` 的 `appearance.primaryColor`。

### 2.3 用色规则

- **主操作**（提交、新建、确认）只用 `--accent-primary`，一个页面同时最多 1 个主按钮。
- **状态色**（success/warning/danger）只用于状态徽章、提示框，**不用于装饰**。
- **危险操作**（删除、归档）按钮用 outline 风格 + danger 描边，避免全红实心按钮。
- **冲突严重度**`severity-*` 系列只在冲突/期限模块使用，不与其他色混用。

## 四、间距 & 圆角 & 阴影

| 项 | 值 | 用例 |
|---|---|---|
| 间距单位 | Tailwind 默认 4px 制 | `gap-2` = 8px，`gap-4` = 16px |
| 页面边距 | `px-8 py-6` | 主内容区四周留白 |
| 卡片内边距 | `p-5` | 20px |
| 圆角 - 小 | `rounded-md` (6px) | 输入框、徽章 |

### 6.2 响应式

| 断点 | 行为 |
|---|---|
| < 1024px | Sidebar 收起为图标 |
| < 768px | V1 暂不优化（律师主要桌面用），保证不崩 |

### 6.3 抽屉 vs 整页规则（决策 §10）

| 场景 | 形式 | 理由 |
|---|---|---|
| **新建** Intake / Matter / Client / Note / Task / FeeEntry | 右侧 `Sheet` 抽屉 | 不离开列表上下文，操作快，关闭无感 |
| **编辑**简单字段（改状态、改备注、加标签） | 内联编辑 / 行内弹层 | 一两个字段不值得开页面 |
| **编辑**复杂表单（案件信息、合同结算单） | 进入整页编辑 | 信息密度高，需要并行查看相关数据 |
| **查看**案件 / 客户 / 程序详情 | 整页（有 URL） | 可分享、可加书签、回流便 |
| **查看**只读小数据（某条 Note / Task 详情） | `Popover` 浮层 | 浮层即够 |
| **冲突检索**结果详情 | 整页 + 抽屉混合 | 检索结果整页，命中项详情可选择"在新抽屉看"或"跳目标案件" |

**抽屉规范**：
- 宽度：默认 `max-w-2xl`（约 672px）；多字段表单可 `max-w-3xl`
- 关闭：`Esc` / 点遮罩 / 右上 `×` / 提交成功后自动关闭
- 未保存离开：弹 confirm

- 整页背景：`--bg-base` 之上叠加一层超弱径向渐变（从右上角主色 5% → 透明），打破纯色单调

- Hero 右侧"今日焦点"卡片：玻璃质感 + 主色 12% 渐变内描边 + 主色 25% glow
- 数字字体：金额和倒计时统一用 `font-mono tabular-nums`，避免抖动
- 进入页面时：四块区域 stagger 入场（每块延迟 60ms），用 `framer-motion`
- 没数据时：四种占位插画（不用空白），符合科技感的极简线条插图

- 执行不出现在普通诉讼/仲裁程序的预设环节中；需要执行时通过程序链新增独立执行程序。
- 可选预设环节和自定义环节在标题区显示"移除"入口；已有任务、阶段材料或专项记录时只提示保留数据，完整隐藏状态待 `MatterStage` 增加状态字段后实现。

- 字段标签右对齐，宽度固定 96px，输入区 flex
- 区段分隔线（"当事人"、"时间与人"等）字号 12px、灰色、左侧带 2px 短主色线
- 选中态按钮：背景 `--accent-primary` 30% 透明 + 1px `--accent-primary` 边 + 8px 主色 glow
- 未选按钮：透明背景 + `--border-default` 边；hover 时边变 `--accent-primary` 50%
- 主按钮"创建案件"：主色实心 + 12px glow，加载态变为带 spinner 的"创建中..."

**校验与体验**：
- 必填项空：字段红描边 + 字段下方 12px 红字提示，不弹 toast
- 客户/联系人 [+] 弹**二级抽屉**（叠在当前抽屉上、宽度 480px），新建后自动回填
- 案由搜索：300ms debounce，按 `category` + 模糊匹配 `name|shortName|pinyin|keywords`
- 关闭抽屉：若有改动弹 confirm "尚未保存的内容会丢失，确认关闭？"
- 创建成功：抽屉滑出，列表顶部插入新行并高亮 1.5 秒

| 交互 | 实现 |
|---|---|
| 全局快捷面板 `⌘K` | shadcn `Command` 组件，搜索案件/客户/跳页面 |
| 列表行悬停 | 背景色 `--bg-overlay`，左侧 2px 强调色亮条 |
| 数字滚动 | 工作台 KPI 数字加载时 400ms count-up |
| 状态切换 | 按钮微弹 + 状态徽章颜色 cross-fade |
| 抽屉打开 | 右侧 `Sheet` 滑入 200ms，背景 `bg-glass` 渐显 |
| 表单错误 | 字段红描边 + 左侧 shake 8px 一次 |
| Toast | `sonner` 右下角，4 秒后消失，可堆叠 |
| 骨架屏 | 列表/详情加载用 shadcn `Skeleton`，禁用 spinner |

**禁忌**：
- ❌ 不在表格行加 hover 动效（性能差且廉价）
- ❌ 不在按钮 hover 时改大小（用颜色 + 描边变化即可）
- ❌ 不用渐变色填充按钮背景
