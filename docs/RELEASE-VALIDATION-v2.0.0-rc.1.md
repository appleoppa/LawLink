## 已知缺口与未覆盖范围

1. **1.x 原库升级未验证且不支持直接执行。** 当前基线创建新库结构，不能替代旧数据转换；已撤回旧说明中适用于所有既有库的直接 resolve 指引。
2. **新库审计防删触发器缺失。** 归档历史迁移 `20260920000001_audit_fix_hardening` 包含 `audit_log_no_delete`，当前基线不包含该定义；隔离新库查询 `AuditLog` 的自定义触发器为 0。模型比较不会发现该缺口。应用层审计仍在，但不能据此宣称数据库层防删已生效。需另行补齐手写约束并验收，本次未修改 Schema 或生产库。
3. 未执行从收案到归档、借阅申请到归还的完整浏览器写入闭环；页面响应检查不等于业务验收。
4. 未实测多用户并发、OCR 识别可信度、各法院平台取件兼容性、全套云服务器 / Docker / Caddy 部署与灾难恢复。
5. 短信来源逐页定位、开庭改期更正、环节级归类、专门分诊界面和提醒多实例协调仍未完成。

**发布定位：仅作为独立空库试用的 Pre-release，暂不用于正式案件。** 后续正式版应先处理上述数据库保护与升级边界，再完成对应验收。GitHub CI 结果以本候选版提交的实际工作流为准，不引用旧提交绿灯。
