## 三、原则（已写入 AGENTS.md）

1. 一屏一个主操作，放顶栏；页头只放次要操作。
2. 选项 ≤5 用 chip，>5 用下拉；有搜索需求（案由、客户、管辖地）用可搜索下拉。
3. 禁止原生 `confirm / prompt / alert`；危险操作用 `confirmDialog`（红色确认按钮 + 后果说明），需要录入的用表单弹窗。
4. 日期统一 `YYYY-MM-DD`，时间 `HH:mm`，均按 Asia/Shanghai。
5. 已实现的能力必须有可达入口；按配置状态显示，不做假入口。
