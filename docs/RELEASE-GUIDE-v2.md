# LawLink 2.0 使用与升级说明

正式版 `v2.0.0` 指向以 `597404b` 为基线、包含测试时钟修复和发布文档的正式提交。包版本已统一为 2.0.0；旧文档及升级脚本中保留的 1.4.0 为内部名称。

## 升级

当前权威步骤为[1.3.x 升级指南](./RELEASE-GUIDE-v1.3.md#从-v13x-升级迁移基线重建必读含手工步骤与增量脚本)：备份、停止写入和副本演练后，执行增量 SQL → 两次完整名称的 resolve → deploy。不得只做基线标记。旧实收转为待确认及 moneyKind 回填规则必须核对。

RC1 已应用完整基线和借阅迁移的库，不运行 1.3.x 增量脚本；先在副本核对结构与迁移记录，再部署新增守卫迁移。

## 首次登录后的配置顺序

设置个人资料、律所、岗位与团队、事项审批、财务确认资格和归档制度，再按需设置外部接入。新增账号证件照片选填。系统管理资格不替代业务权限。

全新安装见 [README](../README.md)，只初始化管理员及系统基础配置，不包含展示案件、测试业务记录、附件或备份。

## 验证范围

升级路径、守卫恢复及业务主流程已验收。多用户并发、OCR 可信度、法院平台兼容性、借阅到期真实时间验证仍未覆盖；短信逐页来源回看等功能仍未完成。详见[变更记录](../CHANGELOG.md)与[发布验证](./RELEASE-VALIDATION-v2.0.0.md)。
