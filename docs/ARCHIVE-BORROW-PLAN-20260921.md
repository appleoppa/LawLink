# 归档案卷借阅（调卷）设计方案（F-6，待批）

> 日期：2026-09-21。来源：第六轮体检 F-6——归档做得很重（收尾清单、一致性指纹、
> 审批、不可变），但归档**之后**没有调卷线：客户回头咨询、再审、律协检查、税务
> 核查都需要「借阅申请 → 审批 → 限时可读 → 留痕」。本方案为设计冻结稿，实施前
> 需叶森批准（含 Schema 迁移，走 create-only 审批流程）。

## 一、原则

1. **归档不可变性不变**：借阅只开放在线只读访问，不复制、不解包、不改动归档记录；
2. **限时**：批准即授予一个有时效的访问资格（默认 30 天，可指定），到期自动失效，
   读取路径实时校验（不靠隐藏入口）；
3. **全程留痕**：申请理由、审批意见、访问开始/结束、到期未归还提醒全部审计；
4. **复用既有对象**：审批走统一工作台既有框架（新增审批类型），访问控制复用归档
   读取的鉴权链，不另造第二套卷宗视图。

## 二、数据模型（新表，纯增量）

```
ArchiveBorrowRequest
  id            cuid PK
  archiveRecordId  → ArchiveRecord（固定到具体归档包版本）
  applicantId   → User
  reason        String（借阅事由，必填）
  scope         String（WHOLE_VOLUME 整卷 / LISTED 指定材料清单 Json）
  status        PENDING / APPROVED / REJECTED / RETURNED / EXPIRED
  approverId?   → User
  decidedAt?    / rejectReason?
  accessUntil?  DateTime（批准时 = 决定时刻 + 有效天数，默认 30）
  returnedAt?
  createdAt / updatedAt
```

## 三、流程

1. **申请**：归档台账（/archive）与案件档案页「已归档」态提供「申请借阅」入口，
   必填事由 + 范围（整卷 / 勾选材料）；
2. **审批**：统一审批工作台新增「借阅审批」类型——审批授权沿用归档审批持有人；
   单人执业可走自确认清单（沿用既有可配机制，默认排除项不涉及）；
3. **限时可读**：批准后申请人获得该归档的临时访问资格；读取路径（归档详情、
   材料在线查看）在常规归档权限之外校验「有效借阅单」；到期即失效；
4. **归还与到期**：申请人主动「标记已阅毕/归还」，或 accessUntil 到期自动 EXPIRED；
   到期前 3 天与当天站内提醒（走 F-1 台账：objectType ARCHIVE_BORROW、kind OFFSET）；
5. **留痕**：BORROW_REQUEST / APPROVE / REJECT / ACCESS_OPEN（首次访问时刻）/
   RETURN / EXPIRE 全部审计；审计与借阅单自身即为律协检查的应答材料。

## 四、明确不做

- 不做实物卷宗借出登记（本系统只管电子卷；纸质流转线下台账）；
- 不做下载/导出（在线查看经既有鉴权与水印；导出继续走既有整案导出权限）；
- 不改变补充归档（supplement）与归档不可变语义。

## 五、实施批次

1. Schema 迁移（create-only 审批）→ 2. 审批类型接入 + server actions →
3. 读取路径临时资格校验 + 到期提醒（台账登记）→ 4. UI（申请入口/工作台卡片/借阅状态）。

## 六、验收

1. 无有效借阅单的非权限人访问归档被拒（专项用例）；
2. 批准后限时可读、到期自动失效（读取路径实时校验，非仅 UI 隐藏）；
3. 全流程审计可回放（申请→审批→访问→归还/到期）。
