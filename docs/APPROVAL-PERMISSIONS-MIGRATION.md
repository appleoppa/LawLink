## 当前管理员配置路径（2026-09-06 更新）

1. 确认并执行本地增量迁移，核对数据库与 Prisma 模型。
2. 管理后台 → 审批权限：先建立用章事项，选择各事项允许的印章。
3. 建立权限组，按操作和案件类别设置规则，用章规则另选事项和章种；在同一表单分配账号。
4. 所有账号（包括系统超级管理员）均须按业务分配权限组；系统管理身份不授予审批或盖章回填资格。
5. 单人执业如需本人审批，显式开启例外；否则默认禁止。
6. 事项授权始终生效，无启用开关和旧角色回退；空权限组不产生任何审批授权。
7. 新系统不接收未分类用章申请；事项缺失时直接阻止提交。
