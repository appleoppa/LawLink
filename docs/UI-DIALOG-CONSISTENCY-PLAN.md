# 审批与弹窗风格统一

状态：2026-09-06 叶森已要求继续，将已确认的立案审阅风格扩展至其他审批及弹窗。

## 实施顺序

1. 公共 Dialog / Sheet：统一实体表面、标题字号与对齐、圆角、操作区分隔和窄屏边距；保留 Radix 焦点、关闭、嵌套弹窗及各调用方宽度。
2. 其他审批：文书、归档、开票、用章在审批工作台中复用宽幅审阅框架；申请内容、附件、处理记录分区；桌面固定操作栏，窄屏正文可滚动并始终可到达操作区。归档清单与文件核验保留在资料页，切换页签不能清掉核验结果。
3. 普通表单：将用章申请、任务/提醒、常用申请表的标题/正文/底部操作分开；已有完整表单（开票、收案）沿用同一公共语言。简单确认、资料预览、搜索保持适合内容的大小与交互。

## 边界

仅修改呈现，不改 Schema、权限、Server Actions、校验、审批决定、附件范围或审计。保留当前工作区其他任务改动，复杂文件只抽出呈现边界。界面数据均来自现有服务，不写入效果稿虚构数据。

## 验收

审批：有权处理、只读历史、待开票/待盖章、归档缺项、无附件、长文件名、意见与核验结果保留。
普通弹窗：表单提交边界和必填校验、取消/关闭、键盘焦点、下拉菜单、小屏底部操作可达性。实际浏览器检查 1440 / 1280 / 390 宽度；运行 lint、typecheck、Prisma validate、build 及相关测试，确认本地服务归属和可访问性。


## 本轮完成与验收

- 公共 Dialog / Sheet 已统一实体白色表面、左对齐标题、分隔线、关闭按钮、圆角与操作间距。现有各类普通弹窗共享基础样式；搜索、预览及其他专用内容保持自身结构。
- `ReviewDialogContent` 与共享样式承接文书、归档、开票、用章审批；立案审批也使用同一组布局样式。摘要来自真实字段，历史未固定材料不写成零份送审材料；附件逐件权限、审批/执行区分、归档例外核验及既有回调继续生效。
- `FormDialogContent` / `FormDialogBody` 已接入用章申请、开票申请（全局与案件内）、日程事项、案件提醒、外部联系人、资料上传、公告、财产保全及法院短信录入，共 10 个表单文件。用章申请进一步分为用章事项、文件信息、材料与说明；简单表单保持紧凑高度。
- 浏览器验收：1440×900、1280×800、390×844；实际查看文书待审、归档历史材料缺失、开票只读、用章已驳回历史、附件与意见保留、申请入口、用章/开票/日程表单。窄屏长表单操作固定、正文可滚动，表单取消和必填提示有效；没有执行真实审批或提交业务数据。验收草稿已清空。
- 嵌套菜单 Esc 回归检查发现不同 Radix dismissable-layer 版本各自维护浮层栈，造成关闭菜单时连带关闭表单。项目 overrides 统一为已使用的 1.1.12，锁文件去除重复依赖，不增加全局依赖；自动测试与真实浏览器均确认 Esc 仅关闭菜单、保留表单。
- 最终 53 个测试文件、428 项测试全部通过；lint、typecheck、Prisma validate、生产构建通过。前轮其他模块引起的全仓库验证阻塞已经消除。3000 端口进程目录确认为本仓库，实际页面可访问。
