## 第五版：案件档案重排 + 取消独立委托模块（2026-09-16 用户确认）

**案件档案的版面**（不是简单加列，而是按语义重排）：
1. **当事人对阵区**（整页首屏主视觉）：左「我方」、右「对方」，中间一个圆形关系符；第三人及其他参与人在下方一行。
2. **案件要素一张卡、内部分区**：分区依次为「案由与请求」「管辖与承办」「委托与收费」「收案与登记」，每个分区一条标题带（图标 + 标题 + 右侧操作）。字段使用自适应网格（每列最小 260px，能放几个放几个），长文本字段（诉讼请求、事实摘要、服务范围、付款节点等）占整行。**不用左右两栏**：两栏会因内容多少产生高度差，单卡分区既没有高度不齐，也不会留空格。
3. 自定义字段并入「收案与登记」，编辑入口在该卡片头部。



- **案件是一案一签**：不再设「委托」模块。收案登记的收费约定（收费方式、约定收费 / 基础办案费、风险代理收费方式、付款节点、收费说明）随案件展示在「案件档案 · 委托与收费」。
- **委托代理合同**：收案时上传的合同转案件后即为本案材料；「案件档案 · 委托与收费」直接列出合同类材料（可下载），材料视图中同样可见。
- **中途变更收费 / 增加代理程序**：在「委托与财务 · 合同与补充协议」新增一条补充协议（可同时上传补充协议扫描件），原合同保留，合同额自动合计并进入回款进度；不改动原合同、不新增模块。程序本身用「＋ 新增程序」。
- **收案登记的其余内容补进案件档案**：事实摘要、联系人与电话、收案登记日期与登记人。

## 第四版：事项与记录两个入口（2026-09-15 用户确认）

原来的任务、时限、开庭、备忘、记一笔、快递、研判笔记共 7 个入口过于分散，按「要做的事」与「发生过的事」重排：

- **＋事项**（待办区，要做的事）：任务（负责人、截止日可空；无截止日即原「备忘」）、期限（法定 / 约定，带起算依据、确认与调整）、开庭（时间、法庭、地址，同时进日程）。三者用类型标签区分，同一个按钮进入。
- **＋记录**（经办记录区，发生过的事）：沟通（电话 / 微信 / 邮件 / 会见 / 法院沟通）、寄收件（填单号，物流状态自动更新）、研判（判断与分析，列表内仍用独立样式）。完成的事项与系统事件自动落入记录。
- **取消「备忘」叫法**：不再新增；历史备忘作为无截止日的事项显示在待办中，可办结、删除。
- 用词统一：弹窗标题为「添加事项」「添加记录 · 沟通 / 研判 / 寄收件」；原「登记进展」「写研判笔记」「时限」「快递」不再出现在界面上（顶栏主操作改为「添加记录」）。备忘类型不在新增弹窗中提供。
- 数据层不变：Task / Deadline / Hearing / Note / ExpressTracking / ProcedureMemo 各自保留字段，只合并入口与叫法。

## 第三版调整（2026-09-14 用户要求，覆盖第二版的页签划分）

- 页签改为：**案件档案 / 办案进程 / 委托与财务 / 审批用印**。
- **办案进程合并材料与证据**：材料、证据链都随环节展示。环节条上统一切换「本环节 / 全部环节」，待办、材料与证据、经办记录同步按范围显示；本环节范围下待办提示其他环节的待办数与逾期数。证据链按来源材料归属环节，未挂材料的证据项在「全部环节」下显示。类案检索入口在证据链头部，AI 审查总览在「全部环节」下的材料之后。
- **案件档案**：主栏为基本信息（已合并当前程序的案号、机构、法官、书记员、立案 / 结案、裁判结果）、当事人（v1.3.2 紧凑卡片）、自定义字段；侧栏为承办团队、最近待办、最近记录。
- **快递与备忘并入经办记录**：作为记录类型出现（可筛选），备忘可办结 / 恢复 / 删除，快递可删除；添加入口在经办记录头部。办案进程不再设侧栏。
- **委托与财务**：委托合同 + 收付开票 + 分成。
- **审批用印**：用印审批单独一个页签。
- **环节条只放环节信息**（2026-09-16）：名称、状态、开始日期、未完成事项 / 研判 / 材料数、环节说明与移除环节；添加类操作一律在各卡片头部（待办「＋事项」、材料「上传材料 / 从模板生成」、记录「＋记录」），类案检索在记录卡头部。卡片头部添加按钮统一次要样式，实底只用于逾期行的「完成」。卡片名统一为「待办 / 材料 / 记录」。
- **办案环节竖排**：办案进程页签左列为圆形节点竖排的环节列表（跟随滚动，状态、旗标与日期写全，末尾「＋ 添加环节」），中间为环节操作条、待办、材料与证据、经办记录；1100px 以下变回横向滚动。
- **证据链并入材料**（2026-09-14 用户要求）：不再单设证据链模块。材料行显示性质（证据 / 诉辩文件 / 程序文件…）、来源、识别状态与「证据要点 N」标签，点标签展开要点；材料行「＋证据要点」直接挂到该材料；本环节材料可筛选「有证据要点」；未挂材料的要点在全部环节材料末尾列出。类案检索入口移到环节操作条。
- **取消「本环节 / 全部环节」切换按钮**（2026-09-14）：环节竖列最前面增加与环节同样式的「总览」项，点具体环节看该环节、点总览看全部待办、材料（含未归环节材料与未挂材料的证据要点）和全部记录；总览下不显示环节操作条。
- **视觉层次**（2026-09-14 用户确认完整升级）：深墨色头版（标题、案号、状态胶囊），程序卡压在头版底边；页签为带图标与数量的胶囊条并吸顶；区块去灰边框改柔和阴影，标题前加图标方块；当事人按诉讼地位加左侧色条；待办加粗紧迫色带与大号倒计时；当前环节加光晕；委托与财务顶部为大号金额与回款进度条。**案件详情页不使用宋体**（用户反馈显得廉价），标题统一无衬线粗体。
- **侧栏常驻**：承办团队在四个页签常驻；最近待办与最近记录只在案件档案、委托与财务、审批用印页签显示——办案进程的主栏已有完整待办与经办记录，侧栏不再重复（2026-09-16）。

## 第二版修订（2026-09-14 用户反馈后确认，覆盖下文第一版结构）

用户反馈：程序切换过偏、为美观牺牲方便；办案 / 材料 / 证据与争点重复；打开案件首先应看到案件档案；任务与经办日志边界不清；看不到各方当事人的完整信息；「添加环节」应靠近环节。

确认后的结构：

1. **案卷头**：案件名称、案号、状态与异常标签、操作；一行简要列出委托方与对方。
2. **程序栏**（浅色，全页共用）：每个程序一张卡片——程序名、状态、案号、受理机构、承办法官；点击切换，「＋ 新增程序」在程序卡片末尾。
3. **四个页签**：
   - **案件档案（默认首屏）**：基本信息；当事人完整卡片（主体类型、证件类型与号码、法定代表人、联系人、电话、地址、本程序诉讼地位、备注）；本程序信息（机构、法官、书记员、联系方式、立案 / 结案、裁判结果）；委托与收费摘要；承办团队；关联案件；自定义字段。右侧小栏只做提醒：最近 3 条待办、最近 3 条记录。
   - **办案进程**（当前程序）：浅色环节线，「＋ 添加环节」是线末尾的节点；选中环节的操作条；**待办**只放未完成的任务、期限、开庭；**经办记录**只放已发生的事——沟通、研判、完成的任务、已开庭、系统事件，不放材料；快递与备忘单列。
   - **材料与证据**（当前程序）：按环节的材料 + 证据链 + 类案检索 + AI 审查总览。
   - **财务与用印**：委托合同、收付开票、分成、用印审批。

## 设计出发点

律师打开案件只带三个问题：**现在到哪一步、接下来要做什么、要找的东西在哪**。页面主次按这三个问题排；同一份数据只在一处展示。

## 页面结构（自上而下）

1. **案卷头**：案号 / 所内编号 / 法院案号、案件名称、状态与异常标签（逾期、保全临期、归档、受限、服务已完成）、次要操作（上传材料、更多）。
   - **对阵行**：诉讼类为「我方（委托人及诉讼地位）｜对方｜受理机构与承办法官」；非诉 / 顾问为「委托人｜业务或顾问类型｜服务期间」。
2. **进程主线**（深墨底）：当前程序全部环节一条线，含已完成 / 当前 / 风险 / 待办状态、「今天」位置、逾期与开庭旗标；程序切换、新增程序、添加环节在主线头部。点击环节 = 选中该环节。
3. **视图页签**：办案（默认）｜材料｜证据与争点｜委托与财务｜案件档案。
4. **办案视图**（左主右辅）：
   - 环节条：选中环节的说明、清单与本环节操作（添加任务、法定期限、上传到本环节、从模板生成、写研判笔记、移除环节）；保全环节显示保全台账。
   - **下一步**：任务、法定期限、开庭合并，按「已逾期 / 7 天内 / 之后」分组，可切换「本环节 / 全部」；「等待他人」列审批中的用印与归档；已完成任务折叠。
   - **经办日志**：沟通记录、研判笔记、材料入卷、系统事件合成唯一时间线，按环节分段，可按类型筛选；「记一笔」入口。
   - 右栏：我方请求、承办团队、收费进度、审批与用印。
5. **材料视图**：按环节列出材料（来源、识别、AI 审查、预览下载），上传与模板生成。
6. **证据与争点视图**：证据链（含争议焦点类条目）与类案检索入口。
7. **委托与财务视图**：委托合同、收付与开票、用印审批全量。
8. **案件档案视图**：立案与程序信息、全部期限 / 开庭 / 快递 / 备忘台账、自定义字段、AI 审查总览。

## 实现备注（2026-09-14）

- 主线「当前环节」跳过财产保全：保全在保期间持续为进行中 / 临期，属于并行事项，不代表程序推进到保全。
- 下一步：期限按环节说明中的期限类别归到环节，开庭归到名称含「开庭 / 庭审 / 询问」的环节；法定期限「完成」需二次确认。
- 经办日志：材料外键与研判笔记的环节标签优先，其余记录按环节开始时间归段；早于首个环节开始的记录归「收案及其他」；材料上传事件不重复入日志。
- 右栏「诉讼请求 / 服务范围」取收案登记内容，未登记时不显示；刑事案件对阵行中间列为涉嫌罪名。
- 用印审批、收付开票不再用抽屉，「更多」菜单与右栏入口直接切到「委托与财务」视图。
