LAWLINK DESIGN SYSTEM · V4

设计语言 「墨案」

把案件当作案卷来呈现：墨色承载专业与判断，Teal 承载连接与交互，Bronze 承载归档与金线时刻。 高密度但不拥挤——每一层信息都有明确的视觉权重，风险永远比装饰先被看见。

01
任务优先

首屏先回答"现在要处理什么"。行动入口大于统计数字，统计大于装饰。

02
一屏一事

页面级只保留一个主操作；弹层审阅宽幅呈现，表单保持防误操作密度。

03
风险即层级

红只留给阻断，琥珀留给临期，绿只表达完成。颜色有法律后果。

04
来源可溯

材料区分当事人提供 / 调取 / 送达 / AI 识别；事务记录与人工判断分开陈列。
