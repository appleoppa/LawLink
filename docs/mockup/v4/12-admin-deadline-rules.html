期限规则库

法定期限由规则推算生成：起算事件 + 期限 + 顺延规则，并按统一档位阶梯预警。人工修正过的期限将被锁定，规则重算不会覆盖。

① 起算事件发生
如：判决书送达之日、立案受理之日，由程序环节自动记录
② 规则推算期限
按自然日 / 工作日计算，遇法定节假日顺延，生成期限实体
③ 阶梯预警推送
T-7 / T-3 / T-0 / T+1 四档提醒，人工修正后锁定并标注来源
