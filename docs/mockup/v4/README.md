## 一、设计主张

把案件当作**案卷**来呈现。律师的工作对象是卷宗：材料有来源、程序有推进、期限有后果、审批有印。v4 的视觉语言围绕这个隐喻展开，命名「墨案」：

- **墨（Ink #0C1927）**：正文与判断。深墨承载专业感，不参与装饰。
- **连接（Teal #007B7F）**：品牌与当前交互。沿用叶森选定的 teal，但收窄职责——只出现在品牌、主操作、选中态与"进行中"的品牌语境。
- **金线（Bronze #8A6B3E）**：归档与品牌性时刻。结案、归档、制度依据使用青铜金线，替代"绿色=完成"的俗套。
- **宋体只给案件**：案件名称、登录主张使用宋体，唤起法律文书的纸感；其余界面保持系统黑体的高密度工作台节奏。

### 与 v3.4 的关系

v3.4 的高密度浅色工作台、Apple 式交互纪律（动效 token、按压反馈、hover 门控）全部保留。v4 在其上补三层：

1. **颜色纪律成文**：红只表达风险/阻断，绿只表达完成，teal 只表达品牌与当前交互，bronze 只表达归档（v4 重构方案原则 5 的视觉化）。
2. **四个签名母版**：让"案件感"长在界面上，而不是靠文案提示（见下）。
3. **业务语义可视化**：材料来源 chip、事务记录与人工判断分离、期限规则推算链——把改进报告里"来源可溯"的主张变成看得见的界面承诺。

## 二、四个签名母版

| 母版 | 形式 | 语义 |
|---|---|---|
| **案卷脊 Spine** | 列表行左侧 3px 状态色条 | 列表即档案架，扫一眼分拣风险：红=逾期、琥珀=临期、蓝=进行、绿=结案、金=归档 |
| **程序链 Chain** | 横向 stepper，当前环节呼吸墨点 | 程序独立推进（一审/保全/执行），当前环节 teal 呼吸环，风险环节琥珀"!" |
| **风险阶梯 Ladder** | 四格高度递增的条 | 期限紧迫度：正常(1)→关注(2)→临期(3)→逾期(4)，红永远只属于最后一格 |
| **审阅印 Seal** | 微倾双环圆印 | 审批终局与用印回填的收口意象，克制而不做成贴纸 |

## 四、Token 速览

完整定义见 `design-system.css`。关键差异（相对 v3）：

- 画布 `#F2F4F3`（更中性的灰绿调），凹陷井 `#E9EDEB` 用于输入与分段底。
- 文本四级：`#0C1927 / #414E5A / #68747F / #98A3AD`。
- 语义色统一配 `*-bg` 与 `*-line` 三件套，徽章/横幅/边框不再临时配色。
- 圆角收敛为 4/6/8/12/16；阴影四级（card/hover/pop/float）+ 顶部内高光。
- 等宽字体只给金额、案号、倒计时（tabular-nums）。
